### ⚡ What I Do & Engineering Focus

- 🏛️ **Full-Stack Commerce Architecture**: Engineering high-performance e-commerce flagships using **Next.js 15 (Turbopack, App Router)** with sub-second page loads and 100/100 Core Web Vitals.
- 📦 **Logistics & Webhook Automation**: Integrating automated courier booking and real-time order dispatch webhook pipelines (**Pathao**, **Steadfast Logistics**).
- 📊 **Server-Side Tracking & Infrastructure**: Implementing **Meta Conversions API (CAPI)** server-side event routing to bypass client ad blockers and scale conversion tracking accuracy.
- 🔒 **Data & Edge Systems**: Architecting relational databases with **PostgreSQL**, **Supabase**, Row-Level Security (RLS), and serverless API endpoints.
